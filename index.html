Positioning the investment

  • Frame it as protecting the programme's market position, not just its content — an OP programme competes for delegates against every other option in the market, not just internally against other GIBS programmes.
  • Base the Learning Lead's scope on which needs actually apply to this programme — the hours above only include tasks tied to needs ticked in Step 01, not a flat percentage of everything.
  • Flagship status carries no hours of its own — use it as a reason to execute the other selected needs more rigorously, not as a line item.
Where this guidance comes from

Hours and task notes are taken directly from the OP Learning Lead Calculator (.xlsx, 06/11/2025). The mapping from each need to specific tasks is a working agreement between PAL and the OP SPM, not yet a published document. Priority values exist in the source calculator but aren't used here, at GIBS's request — that column wasn't scrutinised when the source was built. The multi-programme guidance note is shown as-is from the source; GIBS flagged that it hasn't held up cleanly enough in practice to build into a working model.

Internal reference tool for the OP Learning Lead and OP SPM. Not a substitute for the current Learning Lead Decision Framework, OP costing sheet, or a conversation with PAL.
